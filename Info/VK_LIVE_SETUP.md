# VK Видео Live в YawaChat

YawaChat работает с VK Видео Live двумя независимыми способами.

| Что нужно                                       | Вход в аккаунт |
| ----------------------------------------------- | -------------- |
| Чтение публичного чата любого канала             | не нужен       |
| Ответы бота в чат, награды за баллы, режимы чата | нужен          |

Чтение публичного чата работает сразу: добавьте канал по имени из адреса
`live.vkvideo.ru/<канал>` — и сообщения появятся в общей ленте.

Ниже — как включить вход, чтобы заработали ответы бота и награды.

## 1. Создайте своё приложение VK

1. Откройте <https://dev.live.vkvideo.ru/apps> и войдите через VK ID.
2. Нажмите **Создать приложение**.
3. Заполните форму:
   - название, описание и иконка — любые;
   - **URL для web-push** оставьте пустым;
   - в поле redirect-ссылки вставьте ровно этот адрес:

     ```text
     http://localhost:8579/yawachatredirecturl
     ```

4. Нажмите **Создать** и сохраните **ID приложения** и **секретный ключ** —
   они понадобятся на следующем шаге.

## 2. Впишите свои данные в сборку

Все данные приложения лежат в одном месте — в начале файла
`webview2/VkLiveAuth.cs`, блок `VkLiveApp`:

```csharp
public const string ClientId = "ВПИШИТЕ_СВОЙ_CLIENT_ID";
public const string ClientSecret = "ВПИШИТЕ_СВОЙ_CLIENT_SECRET";
public const string RedirectUri = "http://localhost:8579/yawachatredirecturl";
```

- `ClientId` — ID приложения из кабинета;
- `ClientSecret` — секретный ключ приложения;
- `RedirectUri` — тот же адрес, что вы указали при регистрации. Если меняете
  его здесь, поменяйте и в кабинете VK: адреса должны совпадать посимвольно.

Больше нигде ничего менять не нужно: вход, продление и отзыв доступа,
отправка сообщений и награды берут данные только отсюда. После правки
пересоберите приложение.

## 3. Войдите в приложении

1. Откройте **Настройки → Чат-бот**.
2. В карточке **VK Видео Live** нажмите **Войти**.
3. В браузере подтвердите доступ. Страница сообщит, что можно вернуться
   в YawaChat, — вход завершён.

После входа:

- канал вашего аккаунта добавляется в список каналов автоматически;
- награды за баллы канала подтягиваются в раздел звуков наград;
- бот может отвечать в чат VK Видео Live;
- доступ продлевается сам, повторный вход не требуется.

Кнопка **Выйти** отзывает доступ у площадки и стирает сохранённые данные входа.

## Запрашиваемые права

Отправка сообщений, настройки чата, баллы канала с наградами и заявками на
них, роли канала и данные трансляции. Набор прав задан в том же файле
(`Scopes`) — если каких-то возможностей не нужно, права можно сократить.

## Что VK не разрешает приложениям

Официальное API площадки не даёт удалять сообщения, выдавать баны и таймауты
и очищать чат — эти действия выполняются только в чате на сайте. В приложении
для VK Видео Live доступны режимы чата: медленный режим, «только смайлы» и
ограничение доступа к чату.

Закрепление сообщений у VK тоже отсутствует — отправляйте ответ без него.

## Если что-то не работает

- **«Не заданы данные приложения»** — не заполнены `ClientId`/`ClientSecret`
  в `webview2/VkLiveAuth.cs`.
- **Браузер сообщает о неверной ссылке возврата** — адрес в кабинете VK и в
  `RedirectUri` различаются.
- **«Порт занят другой программой»** — освободите порт 8579 либо укажите
  другой адрес и там, и там.
- **«На канале сейчас нет трансляции»** — VK принимает сообщения в чат только
  во время эфира.
- **Награды не загрузились** — список наград отдаётся только владельцу канала:
  войдите тем аккаунтом, которому принадлежит канал.

Информация о площадке: <https://live.vkvideo.ru/>, кабинет разработчика:
<https://dev.live.vkvideo.ru/apps>.
